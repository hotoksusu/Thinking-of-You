## 권한·승인 경계

- 이번 승인: GitHub 저장소의 별도 검토 브랜치 `contents:write`에 해당하는 코드 커밋/푸시. 강제 푸시·main 병합 없음.
- 이번 미승인: 운영 D1 생성/SQL 적용·복원, Sites 소스 main 동기화·버전 저장·정식 배포. 관련 도구·쓰기 자격증명을 요청하지 않는다.
- 솔라피: 사용자가 실발송 보류를 명시했다. 실제 키 설정·번호 승인·실발송은 이후 별도 절차로 진행한다.
- 이전 자동 승인 거절은 Sites 쓰기 자격증명 전달/게시 권한에 관한 것이었다. GitHub 별도 브랜치 승인이 그 거절을 우회하는 근거는 아니며, 이번에는 승인된 GitHub 경로만 사용한다. 새로운 거절이 발생하면 우회하지 않고 조치·사유·필요 권한을 보고한다.
