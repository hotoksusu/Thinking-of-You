# 모바일 UX/UI 개선 결과 — 2026-10-14

## 수정 범위와 기존 연결
- `/` → `/patient`(병원 초대 링크 안내), `/demo/patient`(별도 데모 저장소), `/hospital`(병원 소개), `/hospital/login`(기존 로그인).
- 실제 환자: `/i?token=…` → 기존 본인 확인 → `/app/patient` → `/app/patient/checkin`, `/history`, `/hospital`.
- 동일 환자 컴포넌트를 쓰는 공개 데모에도 반영. 기존 환자 인증, 병원/관리자 화면, 저장소 키, 회복 추이 및 위험 신호 계산은 유지.
- 기존 저장은 브라우저 localStorage 기반. 이번 작업에서 서버 저장·실시간 병원 상담 기능을 신설하지 않음.

## 콘텐츠 정리
- 유지: 세밀한 기록, 안전 경고, 회복기록, 실제 진료 일정·후속 확인, 보호자 동의 및 대리 입력, 기존 로그인/가입 경로.
- 축소: 병원과 연결되어 있다는 반복 설명, 완료 후 장문 설명, 기록 장려 문구.
- 이동: 상세 회복 추이는 기존 회복기록으로 유지. 보호자 도움은 접힌 영역에서 접근.
- 삭제: 오늘 화면의 반복 일반 도움 카드와 장식 캐릭터. 다른 화면의 캐릭터 기능은 유지. 병원 페이지의 임의 예시 전화번호·주소·운영시간과 동작을 흉내 내던 버튼 제거.

## 기능
- `CheckIn.initialCondition`은 선택 항목을 저장하는 선택적 필드로 추가. 기존 기록과 호환하며 수정 시 보존.
- 저장 중/성공/실패 처리, 기존 일일 중복 방지 및 수정 로직 유지.
- 상세 입력은 환자/데모/날짜/수정 여부/보호자 여부로 분리한 sessionStorage 초안으로 복원. 저장 완료 시 초안 제거.
- 기존에 존재하는 위험 신호는 기록 위에 우선 노출. 새로운 증상 분류 알고리즘 없음.
- 최근 최대 7개 기록을 사용자 화면에 표시하고 직접 복사. 자동 외부 전송 없음. 클립보드 실패 안내 제공.
- 연락처 미등록 시 퇴원 안내문/수신 문자 확인과 병원 공식 연락처 검색 제공. 운영시간 외 지원은 미등록 상태로 안내.
- 응급 예시는 [찾기쉬운 생활법령정보의 응급환자 신고 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=1&cciNo=2&cnpClsNo=1&csmSeq=906)를 참고. 진단·치료 판단을 추가하지 않음.
