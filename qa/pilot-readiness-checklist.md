# 의료기관 파일럿 승인 체크리스트

## 합성 데이터 제품 시연

- [x] 정형외과 수술·퇴원환자 관리에 초점을 맞춘 도입 설명과 비공개 데모 생성.
- [x] 환자 체크인, 병원 조치와 후속 업무, 월간 리포트 및 CSV를 합성 데이터 경로에 연결.
- [x] 도입 문의에서 담당자용 정보와 동의만 접수하고 합성 데이터 확인.
- [x] 가격 가설을 내부 제품 문서에 기록.

## 실환자 파일럿 개시 전 승인

- [ ] 병원 책임자와 정형외과 의료진이 대상·운영시간·업무 담당·휴일 대체·응급 이관 절차를 승인한다.
- [ ] 회복관리 업무용 분류의 임상 적합성과 디지털의료제품법 관련 해당성을 검토한다.
- [ ] 개인정보 보호법과 의료법 관련 처리 근거·민감정보, 안내와 동의, 위수탁 계약, 개인정보 권리 행사, 보존·파기 기준을 검토한다.
- [ ] 병원별 실환자 링크 전달 경로, 본인 확인 수준, 분실 또는 전달 오류 대응을 승인한다.
- [ ] Sites 인증 신뢰 경계, 분리된 D1, 관리자 권한, 배정 정책, 운영 로그와 비밀키를 운영 환경에서 확인한다.
- [ ] 백업·복구·파기 리허설을 승인하고 운영 실측의 기준, 기간, 지표 담당자를 확정한다.
- [ ] Windows 외 실제 모바일 기기, 확대·보조기술, 고령 사용자 체크인 소요시간을 검증한다.
- [ ] 발송을 사용할 경우 수신 동의·발신번호·승인 템플릿을 확인하고 폐기와 재연락 절차를 정한다.
- [ ] 다녀온/DANYEON 유사 표장과 지정 서비스 선행 조사, 필요시 변리사 자문을 마친다.
- [ ] 변경 및 롤백 문서를 리뷰한 뒤 별도 운영 배포와 실환자 등록 승인을 받는다.
