변경 위험: 기존 localStorage를 자동 이관하거나 인증 권한으로 사용하지 않는다. 기존 마이그레이션을 고치지 않고 추가 스키마를 사용한다. 플랫폼 운영자의 환자 접근은 제거하고 명시적 병원 권한만 인정한다. 신규 서버 운영 업무는 기존 UI를 유지하며 별도 서버 화면에 연결한다. 운영 적용 전 백업·복원 증빙과 롤백 계획 필요.
