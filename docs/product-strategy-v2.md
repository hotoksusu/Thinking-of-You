# 다녀온 v2.0 제품 전략

병원을 다녀온 후에도. 다녀온은 정형외과 수술·퇴원환자의 회복 기록부터 병원의 확인, 연락, 조치와 후속 일정까지 연결하는 B2B2C SaaS다. 구매 결정자는 병원장과 운영책임자다. 업무 사용자는 간호사와 환자관리 담당자이며, 환자는 병원 링크에서 참여한다.

## 초기 판매 상품

| 상품 | 제공 범위 |
| --- | --- |
| 다녀온 체크 | 링크 연결, 통증·움직임·전일 대비 변화 기록, 회복기록 조회, 병원 안내 |
| 다녀온 데스크 | 환자 등록, 업무 목록, 담당자, 응답 확인, 연락·조치 이력, 후속 일정, 관리 종료 |
| 다녀온 인사이트 | 날짜별 응답·회복 그래프와 권한 있는 관리자용 월간 운영 리포트·CSV |
| 다녀온 프로그램 | 병원 승인에 따른 관리기간, 일일 체크인, 업무 확인 시간과 안내. 수술별 맞춤 일정 편집은 추후 검증 |

초기에는 체크, 데스크, 기본 인사이트를 묶는다. 초기 EMR 연동과 앱 설치는 요구하지 않는다. AI, 가족 플랫폼, 고급 분석과 새 진료과는 이후 고객 검증 범위다.

## 경쟁 및 구매 검증

애프터닥은 상담·환자 분류, 사후관리 자동화, 채널 통합과 AI 업무 지원을 제품 전반에 제시한다. 다녀온이 검증할 가설은 정형외과 환자 회복관리, 담당자의 업무 흐름, 가벼운 도입과 구조화된 회복 기록에 집중한 별도 구매 가치다. 기존 애프터닥 사용 병원에도 현재 기능으로 처리하는 부분, 따로 연락하는 업무, 이중 입력 부담과 별도 구매 의사를 각각 질문한다. [애프터닥 공식 제품 소개](https://www.afterdoc.ai/)

기관별 도입 전 업무시간을 업무 단위로 먼저 기록한다. 4주 동안 환자 등록, 유효 체크인, 확인, 후속 조치, 미처리 업무 및 업무시간을 같은 방식으로 측정한다. 별도 제품 구매 의사와 담당자 재사용 의사를 인터뷰로 확인한다.

| 내부 가격 가설 | 조건 |
| --- | --- |
| Pilot | 4주 15만 원, 환자 30명 이내 |
| Standard | 월 29만 원, 신규 관리 환자 100명 이내 |
| Pro | 월 49만 원, 신규 관리 환자 200명 이내 |

가격은 내부 검증에 사용한다. 상담 화면은 연락처와 병원 업무 정보만 접수한다. 실제 결제·청구 기능은 범위에서 제외했다.

## 운영 지표 정의

서버 리포트 날짜는 한국 시간의 시작일과 종료일을 모두 포함한다. 기존 합계 필드는 이전 호출자와의 호환성을 위해 유지한다.

| 지표 | 분자 및 분모 |
| --- | --- |
| 기간 내 등록 | 기간 중 등록 시각이 기록된 환자 |
| 체크인 활성화율 | 기간 내 등록 환자 중 기간 내 유효 체크인을 한 환자 ÷ 기간 내 등록 환자 |
| 응답률 | 관리일정에 해당하는 유효 응답일 ÷ 예정 체크인 환자일. 퇴원일을 1일차로 사용 |
| 미응답률 | 예정 환자일 중 유효 응답 없는 환자일 ÷ 예정 환자일 |
| 응답 확인율 | 기간 내 확인 이벤트가 연결된 유효 응답의 최신 버전 수 ÷ 기간 내 유효 응답 수 |
| 후속 조치 완료율 | 기간 중 생성된 일정과 연결된 기간 종료일까지의 완료 건 ÷ 기간 중 생성된 일정 |
| 관리 종료 | 기간 내 담당자가 종료를 저장한 환자 수. 종료 시각 미기록 상태는 별도 |
| 확인·후속 처리시간 | 수신에서 확인, 일정 생성에서 완료까지의 기록이 각각 있는 표본의 평균 |
| 도입 전후 업무시간 | 같은 분류로 입력한 실제 합계 및 관측일 수. 양측 표본이 있는 경우에만 일평균 차이를 계산 |

분모 0은 측정 전으로 표시한다. 과거 프로그램 기간을 시점별로 보존하는 구조가 없어 기존 보고서의 예정일 계산에는 현재 병원 설정이 적용된다. 실제 표본이 생길 때까지 절감률, 환자 만족도, 재방문율 또는 치료성과를 제시하지 않는다.
