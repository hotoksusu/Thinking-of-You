# Pretendard Care font asset

Unmodified Pretendard Variable v1.3.9, by Kil Hyung-jin.
Source: https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2

Distributed under SIL Open Font License 1.1; see the included `OFL.txt`.
CSS exposes weights 400–700 with `font-display: swap`. This is one 2,057,688-byte WOFF2 with Korean, Latin and numerals; no external font request or additional font family is loaded. The full file preserves unanticipated Korean names rather than a content-only subset. Cold-transfer size remains a measured performance limitation.
